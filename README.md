# ✂️ Brabos da Merck — Landing Page

Landing page desenvolvida para a barbearia Brabos da Merck, localizada em Jacarepaguá, RJ.

🔗 **[Ver site ao vivo](https://brabosdamerck.netlify.app/)**

## Sobre o Projeto

Site de página única criado para apresentar os serviços, preços e localização da barbearia, com foco em conversão via WhatsApp e presença no Google.

## Seções

- Hero com foto de destaque e chamada para ação
- Faixa de aviso animada com informações de funcionamento
- Tabela de preços (cortes, barba, pigmentação, nevou)
- Apresentação da equipe
- Localização integrada com Google Maps
- Botão flutuante de WhatsApp

## Recursos Técnicos

- SEO otimizado com meta tags, Open Graph e Schema.org (JSON-LD)
- Responsivo para mobile e desktop
- Animações em CSS puro
- Fontes Bebas Neue e Rajdhani via Google Fonts
- Deploy via Netlify
